# 01 – Introduction (Intermediate HTML and CSS)

## What this lesson is about
This is the "welcome" lesson of the course. It doesn't teach one big new thing. It shows how much HTML and CSS still exists beyond the basics, so the next lessons make more sense.

## Key points
- HTML has **many more tags** than `<p>`, `<div>` and `<a>`. MDN has a list of all of them (I made my own version: `../../all-html-tags.html`).
- CSS also has **hundreds of properties**. You do not need to memorise them. You look them up when you need them.
- In this course I will learn: SVG pictures, tables, default styles and resets, units, fonts, more properties, advanced selectors, positioning, CSS functions, custom properties (variables), browser support, frameworks, forms and CSS Grid.

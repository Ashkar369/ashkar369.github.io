Main root

The one tag that holds the whole page.

<html>

The box that holds the whole web page. Everything else goes inside it, and every page has exactly one.

Code (can't be shown as a live example – it only goes in the page structure or the <head>, once)
<!DOCTYPE html>
<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

This page itself starts with <html lang="en"> at the very top of the file.

Document metadata

Tags that live in the <head>. They give the browser information about the page but do not show anything on the page itself.

<base>

Sets a default address or default way of opening links for the whole page, so you do not have to repeat it on every link.

Code (can't be shown as a live example – it only goes in the page structure or the <head>, once)
<base target="_self">

This page's <head> uses <base target="_self">: every link opens in the same tab unless the link says otherwise.

<head>

The "backstage" part of the page. It holds the title, settings and styles, and nothing in it is shown as page content.

Code (can't be shown as a live example – it only goes in the page structure or the <head>, once)
<head>
  <meta charset="UTF-8">
  <title>My page</title>
</head>

This page's <head> holds its meta tags, title, base, link and style.

<link>

Connects the page to another file, most often a CSS file or the little icon shown in the browser tab.

Code (can't be shown as a live example – it only goes in the page structure or the <head>, once)
<link rel="stylesheet" href="style.css">
<link rel="icon" href="favicon.png">

This page's <head> uses <link rel="icon"> to set the tab icon (an emoji drawn as SVG).

<meta>

Small pieces of settings about the page, for example which letters it uses (UTF-8) or how it should fit on a phone screen.

Code (can't be shown as a live example – it only goes in the page structure or the <head>, once)
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">

This page's <head> has three: charset, viewport and description.

<style>

A place to write CSS right inside the HTML file, to change colours, sizes and layout.

Code (can't be shown as a live example – it only goes in the page structure or the <head>, once)
<style>
  p { color: navy; }
</style>

This page's <head> has one <style> block that makes the page easy to read.

<title>

The name of the page. It shows on the browser tab and in Google results, not on the page itself.

Code (can't be shown as a live example – it only goes in the page structure or the <head>, once)
<title>All HTML Tags – Ashkar Siyad</title>

Look at your browser tab: it shows this page's <title>.

Sectioning root

The part of the page you actually see.

<body>

Holds everything that is visible on the page: text, pictures, buttons and so on. A page has only one.

Code (can't be shown as a live example – it only goes in the page structure or the <head>, once)
<body>
  <h1>Hello!</h1>
  <p>Everything you see goes here.</p>
</body>

Everything you are reading right now is inside this page's <body>.

Content sectioning

Tags that split a page into big meaningful parts, like the chapters of a book.

<address>

Contact details for a person or company, such as an email or a postal address.

Live example
Ashkar Siyad
Riga, Latvia
ashkar@example.com
Code
<address>Ashkar Siyad<br>Riga, Latvia<br><a href="mailto:ashkar@example.com">ashkar@example.com</a></address>

<article>

A piece of content that makes sense on its own, like a blog post, news story or comment.

Live example

My first blog post

Today I learned HTML!

Code
<article>
  <h4>My first blog post</h4>
  <p>Today I learned HTML!</p>
</article>

<aside>

Side information that is related to the main text but not part of it, like a "Did you know?" box.

Live example
Did you know? HTML was invented in 1991.
Code
<aside>Did you know? HTML was invented in 1991.</aside>

<footer>

The bottom part of a page or section, usually with copyright, contacts or links.

Live example
© 2026 Ashkar Siyad
Code
<footer>© 2026 Ashkar Siyad</footer>

<header>

The top part of a page or section, usually with a logo, title or menu.

Live example
My Website – welcome!
Code
<header>
  <strong>My Website</strong> – welcome!
</header>

<h1>, <h2>, <h3>, <h4>, <h5>, <h6>

Headings from biggest and most important (h1) to smallest (h6). Like titles and subtitles in a school report.

Live example

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6
Code

<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

<hgroup>

Groups a heading together with a small subtitle line that belongs to it.

Live example

Riga Nordic University

Information Systems programme

Code
<hgroup>
  <h4>Riga Nordic University</h4>
  <p>Information Systems programme</p>
</hgroup>

<main>

The main content of the page – the part that is unique to this page. Use it only once per page.

Live example

This is the most important part of a page.

Code
<main>
  <p>This is the most important part of a page.</p>
</main>

This page only uses <main> here, as an example, because a page should have just one.

<nav>

A group of main navigation links, like the menu of a website.

Live example
Home | Forms | Tables
Code
<nav>
  <a href="#main-root">Home</a> |
  <a href="#forms">Forms</a> |
  <a href="#table-content">Tables</a>
</nav>

<section>

A part of the page about one topic, usually with its own heading. This whole page uses one section per category.

Live example

My hobbies

Football and photography.

Code
<section>
  <h4>My hobbies</h4>
  <p>Football and photography.</p>
</section>

<search>

Wraps a search box, so browsers and screen readers know "this part is for searching".

Live example
Code
<search>
  <form>
    <input type="search" placeholder="Search tags…">
    <button type="button">Search</button>
  </form>
</search>

Text content

Tags that organise blocks of text: paragraphs, lists, quotes and so on.

<blockquote>

A longer quote taken from someone else, shown as its own block.

Live example
Learning never exhausts the mind.
Code
<blockquote cite="https://example.com">
  Learning never exhausts the mind.
</blockquote>

<dd>

The description part in a description list (<dl>). It explains the word above it.

Live example
HTML
The language that builds web pages.
Code
<dl>
  <dt>HTML</dt>
  <dd>The language that builds web pages.</dd>
</dl>

<div>

A plain box with no special meaning. You use it to group things so you can style them with CSS.

Live example
I am inside a div box.
Code
<div style="border:1px solid #888; padding:6px;">I am inside a div box.</div>

<dl>

A description list – like a mini dictionary with words and their meanings.

Live example
CSS
Makes web pages look nice.
JS
Makes web pages do things.
Code
<dl>
  <dt>CSS</dt>
  <dd>Makes web pages look nice.</dd>
  <dt>JS</dt>
  <dd>Makes web pages do things.</dd>
</dl>

<dt>

The word or term in a description list. Its meaning comes after it in a <dd>.

Live example
Browser
The app you use to open websites.
Code
<dl>
  <dt>Browser</dt>
  <dd>The app you use to open websites.</dd>
</dl>

<figcaption>

The caption under (or above) a picture inside a <figure>.

Live example
Code
<figure>
  <img src="https://upload.wikimedia.org/wikipedia/commons/a/a9/Example.jpg" alt="Example picture" width="120">
  <figcaption>This is a caption.</figcaption>
</figure>

<figure>

A box for a picture, chart or code example together with its caption.

Live example
Code
<figure>
  <img src="https://upload.wikimedia.org/wikipedia/commons/thumb/6/66/Aurora_borealis_over_Saana_fell.jpg/960px-Aurora_borealis_over_Saana_fell.jpg" alt="Northern lights over Saana fell" width="220">
  <figcaption>Northern lights in Finland.</figcaption>
</figure>

<hr>

A line that separates two different topics on a page.

Live example

Topic one

Topic two

Code
<p>Topic one</p>
<hr>
<p>Topic two</p>

Code

  <li>Bread</li>
  <li>Milk</li>
</ul>

  <li><button type="button">Paste</button></li>

    <ol>

    A numbered list – use it when the order matters, like steps in a recipe.

    Live example
    1. Boil water
    2. Add pasta
    3. Eat!
    Code
    <ol>
  <li>Boil water</li>
  <li>Add pasta</li>
  <li>Eat!</li>

    A normal paragraph of text.

    Live example

    This is a paragraph. It can hold many sentences.

    Code
    <p>This is a paragraph. It can hold many sentences.</p>

    <pre>

    Shows text exactly as you typed it, keeping all spaces and line breaks. Great for code and poems.

    Live example
    Line one
    Line two (indented)
        Line three
    Code
    <pre>
Line one
    Line two (indented)
        Line three
</pre>

    <ul>

    A bullet-point list – use it when the order does not matter, like a shopping list.

    Live example
    • Apples
    • Bananas
    Code
    <ul>
  <li>Apples</li>
  <li>Bananas</li>

    Inline text semantics

    Small tags used inside a line of text to give some words a special meaning or look.

    <a>

    A link. Click it to go to another page, another place on this page, or to send an email.

    Live example
    Visit MDN or jump to Forms
    Code
    <a href="https://developer.mozilla.org" target="_blank">Visit MDN</a> or
<a href="#forms">jump to Forms</a>

    <abbr>

    A short form of a word. Hover over it to see the full meaning.

    Live example
    RNU is my university.
    Code
    <abbr title="Riga Nordic University">RNU</abbr> is my university.

    <b>

    Makes text bold just to catch the eye, without saying it is more important.

    Live example

    Keywords: HTML, CSS

    Code
    <p>Keywords: <b>HTML</b>, <b>CSS</b></p>

    <bdi>

    Keeps text in a different writing direction (like Arabic) from messing up the text around it.

    Live example

    User إيان: 90 points

    Code
    <p>User <bdi>إيان</bdi>: 90 points</p>

    <bdo>

    Forces text to be written in a direction you choose, for example right-to-left.

    Live example

    Hello world

    Code
    <p><bdo dir="rtl">Hello world</bdo></p>

    <br>

    A line break – like pressing Enter in the middle of a paragraph.

    Live example

    Roses are red,
    violets are blue.

    Code
    <p>Roses are red,<br>violets are blue.</p>

    <cite>

    The title of a creative work, like a book, film or song.

    Live example

    My favourite film is Interstellar.

    Code
    <p>My favourite film is <cite>Interstellar</cite>.</p>

    <code>

    Shows a short piece of computer code in a typewriter-style font.

    Live example

    Use <p> for paragraphs.

    Code
    <p>Use <code>&lt;p&gt;</code> for paragraphs.</p>

    <data>

    Shows text for people and hides a machine-readable value for computers behind it.

    Live example

    Product: Blue T-shirt

    Code
    <p>Product: <data value="12345">Blue T-shirt</data></p>

    <dfn>

    Marks the word that is being defined in a sentence.

    Live example

    HTML is the language used to build web pages.

    Code
    <p><dfn>HTML</dfn> is the language used to build web pages.</p>

    <em>

    Stresses a word, like when you say it louder. Usually shown in italics.

    Live example

    I really love pizza.

    Code
    <p>I <em>really</em> love pizza.</p>

    <i>

    Italic text for things like foreign words, thoughts or technical terms, without extra stress.

    Live example

    The word labdien means "good day" in Latvian.

    Code
    <p>The word <i>labdien</i> means "good day" in Latvian.</p>

    <kbd>

    Shows keys the user should press on the keyboard.

    Live example

    Press Ctrl + S to save.

    Code
    <p>Press <kbd>Ctrl</kbd> + <kbd>S</kbd> to save.</p>

    <mark>

    Like a highlighter pen – it makes words stand out with a yellow background.

    Live example

    Don't forget the exam on Friday!

    Code
    <p>Don't forget the <mark>exam on Friday</mark>!</p>

    <q>

    A short quote inside a sentence. The browser adds the quote marks for you.

    Live example

    My teacher said Practice every day.

    Code
    <p>My teacher said <q>Practice every day</q>.</p>

    <rp>

    Fallback brackets for ruby text, shown only in browsers that cannot show ruby properly.

    Live example
    漢(kan)
    Code
    <ruby>漢<rp>(</rp><rt>kan</rt><rp>)</rp></ruby>

    <rt>

    The small pronunciation text shown above a character in ruby annotations.

    Live example
    字ji
    Code
    <ruby>字<rt>ji</rt></ruby>

    <ruby>

    Adds small helper text (usually pronunciation) above East Asian characters.

    Live example
    東京(Tōkyō)
    Code
    <ruby>東京<rp>(</rp><rt>Tōkyō</rt><rp>)</rp></ruby>

    <s>

    Crosses out text that is no longer correct, like an old price.

    Live example

    Price: €50 €35

    Code
    <p>Price: <s>€50</s> €35</p>

    <samp>

    Shows example output from a computer program.

    Live example

    The computer said: File not found.

    Code
    <p>The computer said: <samp>File not found.</samp></p>

    <small>

    Small print, like copyright notes or terms and conditions.

    Live example

    Buy now! Terms and conditions apply.

    Code
    <p>Buy now! <small>Terms and conditions apply.</small></p>

    <span>

    A plain inline box with no meaning. Use it to style a few words with CSS.

    Live example

    My favourite colour is green.

    Code
    <p>My favourite colour is <span style="color:green;">green</span>.</p>

    <strong>

    Marks very important text. Usually shown in bold.

    Live example

    Warning: the floor is wet.

    Code
    <p><strong>Warning:</strong> the floor is wet.</p>

    <sub>

    Subscript – small text that sits lower, like the 2 in H₂O.

    Live example

    Water is H2O.

    Code
    <p>Water is H<sub>2</sub>O.</p>

    <sup>

    Superscript – small text that sits higher, like the 2 in x².

    Live example

    x2 + y2

    Code
    <p>x<sup>2</sup> + y<sup>2</sup></p>

    <time>

    A date or time, written so computers can understand it too.

    Live example

    Class starts at 9:00 on 20 November.

    Code
    <p>Class starts at <time datetime="2026-11-20T09:00">9:00 on 20 November</time>.</p>

    <u>

    Underlines text to show a note, like a spelling mistake mark. Don't use it just for decoration.

    Live example

    This word is mispeled.

    Code
    <p>This word is <u>mispeled</u>.</p>

    <var>

    A variable name in maths or programming.

    Live example

    The area is width × height.

    Code
    <p>The area is <var>width</var> × <var>height</var>.</p>

    <wbr>

    A hint where a very long word may break onto the next line if there is no room.

    Live example

    Supercalifragilisticexpialidocious

    Code
    <p style="width:120px; border:1px dashed #999;">Super<wbr>cali<wbr>fragilistic<wbr>expialidocious</p>

    Embedded content

    Tags that put other things (pages, files, images) inside your page.

    <embed>

    Puts an outside file, like an SVG picture or a PDF, into the page.

    Live example
    Code
    <embed src="https://upload.wikimedia.org/wikipedia/commons/8/84/Example.svg" type="image/svg+xml" width="120" height="120">

    <iframe>

    A window that shows another web page inside your page, like a picture-in-picture.

    Live example
    Code
    <iframe title="Small inner page" width="300" height="90"
  srcdoc="<p style='font-family:sans-serif'>Hi! I am a page inside a page.</p>"></iframe>

    <object>

    An older, general way to put an outside file (image, PDF…) in the page, with fallback text inside.

    Live example
    Code
    <object data="https://upload.wikimedia.org/wikipedia/commons/8/84/Example.svg" type="image/svg+xml" width="120" height="120">
  Picture could not load.
</object>

    <picture>

    Lets the browser choose the best picture for the screen, for example a different image on big screens.

    Live example
    Code
    <picture>
  <source media="(min-width: 900px)" srcset="https://upload.wikimedia.org/wikipedia/commons/thumb/6/66/Aurora_borealis_over_Saana_fell.jpg/960px-Aurora_borealis_over_Saana_fell.jpg">
  <img src="https://upload.wikimedia.org/wikipedia/commons/a/a9/Example.jpg" alt="Big screen: aurora. Small screen: example picture" width="200">
</picture>

    Make the window narrower than 900px and the picture changes.

    <source>

    Gives one option of a file (different format or size) inside <picture>, <audio> or <video>.

    Live example
    Code
    <audio controls>
  <source src="https://upload.wikimedia.org/wikipedia/commons/transcoded/c/c8/Example.ogg/Example.ogg.mp3" type="audio/mpeg">
</audio>

    <svg>

    Live example

    Writes maths formulas, like fractions and powers, with proper maths layout.

    Live example
    ab + x2
    Code

  <mfrac><mi>a</mi><mi>b</mi></mfrac>
  <mo>+</mo>
  <msup><mi>x</mi><mn>2</mn></msup>
</math>

    Scripting

    Tags for adding JavaScript and drawing with code.

    <canvas>

    An empty drawing board. JavaScript draws pictures, charts or games on it.

    Live example
    Code

</script>

    <noscript>

    Text that only shows when JavaScript is turned off in the browser.

    Live example

    (If JavaScript is on, you see nothing extra above.)

    Code
    <noscript>Please turn on JavaScript to use this site.</noscript>
<p>(If JavaScript is on, you see nothing extra above.)</p>

    <script>

    Adds JavaScript code that makes the page do things.

    Live example

    Today is:

    Code
    <p>Today is: <span id="today"></span></p>
<script>
  document.getElementById("today").textContent = new Date().toDateString();
</script>

    Web Components

    Tags for making your own reusable HTML pieces.

    <slot>

    An empty space inside a custom component where you can plug in your own content.

    Live example
    Ashkar Siyad
    Code
    <name-card><span slot="name">Ashkar Siyad</span></name-card>
<template id="name-card-tpl">
  <div style="border:2px solid teal; padding:6px; border-radius:6px;">
    Student: <strong><slot name="name">Unknown</slot></strong>
  </div>
</template>
<script>
  customElements.define("name-card", class extends HTMLElement {
    constructor() {
      super();
      const tpl = document.getElementById("name-card-tpl");
      this.attachShadow({ mode: "open" }).appendChild(tpl.content.cloneNode(true));
    }
  });
</script>

    <template>

    Hidden HTML that is not shown until JavaScript copies it into the page. Like a stamp you can use many times.

    Live example
      Code

<ul id="list"></ul>
<button type="button" onclick="document.getElementById('list').appendChild(document.getElementById('row-tpl').content.cloneNode(true))">Add item</button>

      Obsolete and deprecated

      These tags are old. Browsers may still understand some of them, but you should not use them in new pages. They are listed here only so you recognise them.

      TagWhat it didStatus
      <acronym>Old way to mark a short form of a word.Old – don't use it, use <abbr> instead.
      <big>Made text one size bigger.Old – don't use it, use CSS font-size instead.
      <center>Put content in the middle of the page.Old – don't use it, use CSS text-align: center or flexbox instead.
      <content>An early Web Components placeholder for content.Old – don't use it, use <slot> instead.
      <dir>An old list of folder or file names.Old – don't use it, use <ul> instead.
      <fencedframe>An experimental privacy-focused frame for ads; MDN lists it here as not for normal use.Old – don't use it, use <iframe> instead.
      <font>Changed the font, size and colour of text.Old – don't use it, use CSS (font-family, color) instead.
      <frame>One window inside a <frameset>.Old – don't use it, use <iframe> or normal page layout instead.
      <frameset>Split the whole browser window into several frames.Old – don't use it, use CSS Grid or Flexbox layout instead.
      <image>A wrong, old spelling of the image tag.Old – don't use it, use <img> instead.
      <marquee>Made text scroll across the screen.Old – don't use it, use CSS animations instead.
      <menuitem>One command inside an old pop-up menu.Old – don't use it, use <button> inside <menu> instead.
      <nobr>Stopped text from wrapping to a new line.Old – don't use it, use CSS white-space: nowrap instead.
      <noembed>Fallback content for <embed>.Old – don't use it, use <object> with fallback inside instead.
      <noframes>Text for browsers that could not show frames.Old – don't use it, use no replacement needed – don't use frames instead.
      <param>Gave settings to an <object> plug-in.Old – don't use it, use attributes on <object> instead.
      <plaintext>Showed everything after it as plain text.Old – don't use it, use <pre> or <code> instead.
      <rb>Marked the base text in a ruby annotation.Old – don't use it, use <ruby> with <rt> instead.
      <rtc>Grouped ruby text for semantic annotation.Old – don't use it, use <rt> instead.
      <shadow>An early Web Components shadow-DOM placeholder.Old – don't use it, use attachShadow() in JavaScript instead.
      <strike>Crossed text out.Old – don't use it, use <s> or <del> instead.
      <tt>Showed text in a typewriter font.Old – don't use it, use <code>, <kbd> or <samp> instead.
      <xmp>Showed text exactly as written (like pre).Old – don't use it, use <pre> with <code> instead.
